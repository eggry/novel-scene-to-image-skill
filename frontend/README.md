# 千图百炼 · 工作流面板

纯静态前端，无需编译。包含一组历史任务的三轮图片、提示词和质检记录。

## GitHub Pages

将本目录中的文件作为独立 GitHub 仓库的根目录上传。在 Settings → Pages 选择 Deploy from a branch，选择 main 分支和 / (root)。

打开 https://你的用户名.github.io/仓库名/?taskid=demo 即可静态回放。项目子路径也受支持。在 github.io 域名下直接访问首页会自动进入展示任务。

历史回放不连接 Gateway、不调用模型。输入原文、提示词和图片是公开演示内容。

## 真实任务

部署后端并在“接口设置”填写其地址即可连接真实任务。模型密钥只在后端配置。当前网页不保存密钥或后端地址。

## 发布范围

只发布 frontend 内的文件。不要上传上级目录中的服务端、任务存档、配置、日志或凭据。
